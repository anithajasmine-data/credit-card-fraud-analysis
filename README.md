# Credit Card Fraud Detection | Data Analytics Capstone

## Project Overview

This capstone project analyzes credit card transaction data to explore spending patterns, transaction characteristics, and potential fraudulent activity.

The project combines Microsoft Excel, MySQL, Python, and Power BI to demonstrate an end-to-end data analytics workflow.

## Tools and Technologies

- Microsoft Excel — Data exploration and analysis
- MySQL — SQL queries, joins, filtering, and aggregations
- Python — Exploratory data analysis using Pandas
- Power BI — Interactive dashboards and geographic visualizations

## Project Objectives

1. Explore credit card transaction data.
2. Analyze transaction amounts across categories and customer groups.
3. Examine fraudulent transactions.
4. Explore geographic patterns in transaction activity.
5. Visualize monthly transaction trends and inflation-adjusted values.

## Analysis Performed

### Excel Analysis
Explored transaction amounts, summary statistics, and relationships between variables.

### SQL Analysis
Used SQL queries to investigate transaction counts, spending patterns, merchants, categories, and fraud indicators.

### Python Analysis
Used Jupyter Notebook and Python to explore the dataset and perform analytical operations.

### Power BI Dashboard
Created interactive visualizations, including:

- All Transaction Locations
- Fraud Transaction Locations
- Monthly Transaction Count
- Inflation Adjusted Transactions by Week
- Spending Distribution by Category and Gender
